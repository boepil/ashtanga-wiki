# Anatomical Glossary

This glossary maps key anatomical points using their Sanskrit, Scientific (Latin), and common Hebrew/English names.

## Feet and Legs
| Common (Hebrew/English) | Sanskrit | Scientific (Scientific/Latin) |
| :--- | :--- | :--- |
| Heel (עקב) | Parshni (पार्ष्णि) | Calcaneus |
| Pads of the foot (כריות כף הרגל) | Padangulimula (पादांगुलिमूल) | Metatarsophalangeal joints |
| Sides of the foot (צידי כף הרגל) | Padaparshva (पादपार्श्व) | Lateral/Medial borders |

## Pelvis and Hips
| Common (Hebrew/English) | Sanskrit | Scientific (Scientific/Latin) |
| :--- | :--- | :--- |
| Sitting bones (עצמות הישיבה) | Nishadanasthi (निषाדनास्थि) | Ischial tuberosity |
| Tailbone (עצם הזנב) | Trikasthi (त्रिकास्थी) | Coccyx |
| Hip joints (מפרקי הירכיים) | Katirasandhi (कटीरसन्धि) | Hip joints |
| Pubic bone (עצם החיק) | Bhagasthi (भगास्थि) | Pubic bone |

## The Spine
| Common (Hebrew/English) | Sanskrit | Scientific (Scientific/Latin) |
| :--- | :--- | :--- |
| Sacrum (עצם העצה) | Trikasthi (त्रिकास्थी) | Sacrum |
| Lower back (חוליות המותן) | Kativamsha (कटिवंश) | Lumbar vertebrae |
| Mid back (חוליות החזה) | Urovamsha (उरोवंश) | Thoracic vertebrae |
| Neck (חוליות הצוואר) | Grivavamsha (ग्रीवावंश) | Cervical vertebrae |

| Common (Hebrew/English) | Sanskrit | Scientific (Scientific/Latin) |
